# HUI-CHIAO KUNG｜內容策略 × 品牌視覺

這是一套可直接在瀏覽器開啟的單頁接案作品集網站，以及 3 張社群宣傳圖與對應貼文文案。

## 預覽

直接開啟 `index.html` 即可預覽。網站不需安裝套件、建立帳號或連接外部服務。

## 網站內容

- SEO / GEO 內容、品牌社群、編輯設計三類作品，可篩選並開啟作品預覽。
- 「從哪裡開始」服務推薦、可展開的合作流程與常見問題。
- 社群素材區可下載 SVG 圖檔，也可複製每張圖的搭配文案。
- 需求表單會在本機整理欄位內容供訪客複製，不會傳送或儲存資料。
- 支援手機版導覽、鍵盤操作、焦點提示與減少動態效果偏好。

## 社群素材

`social/` 內的三張 SVG 為 1080 × 1350 px，適合 Instagram 直式貼文比例。SVG 可以用瀏覽器預覽，也可在 Figma、Illustrator 或 Inkscape 調整文字、顏色與版面。

貼文文案與建議標籤見 [`social/captions.md`](social/captions.md)。

## 作品素材與來源

網站作品縮圖取自工作資料夾內兩份提案簡報的案例頁，再轉為 WebP 縮圖供網頁載入。網站使用簡報案例中已呈現的工作類型；沒有替案例新增客戶推薦或自行推算數據。若要公開完整客戶名稱、成果或原始作品，請再按授權情形補充。

## 品牌色彩

網站與新製社群素材沿用 `new)SEO_GEO一條龍行銷提案簡報` 的主要配色：

- 靛藍：`#4F46E5`
- 亮藍：`#428BF7`
- 深色文字：`#111215`
- 淺色底：`#F8F9FA`
- 中性灰：`#5C636A`

另一份品牌視覺簡報的案例原圖保留其原始色彩，方便客戶理解各案設計方向。這些案例色不套用到網站主介面。

## 上線前可補充

- 檢查中英文姓名、服務文案與作品公開授權。
- 在 `index.html` 補上公開聯絡方式或社群連結。聯絡資訊尚未提供，因此目前的聯絡表單只會產生可複製的需求摘要，不會寄出郵件。
- 若需正式收件，可將表單接到你選用的表單服務或後端；目前網站是純靜態檔案。
